# Databricks Data Engineer Professional

✅ **Earned** — [credential](https://credentials.databricks.com/d9114e66-f556-4da1-a383-fc65cb512027#acc.8lQgipFn)

Study notes organized by the official exam sections, one folder per section,
ordered by section number. The weight next to each section is its share of
the exam — spend your study time accordingly.

| # | Section | Weight |
|---|---------|--------|
| 01 | [Developing Code for Data Processing using Python and SQL](01-developing-code-for-data-processing/) | 22% |
| 02 | [Data Ingestion & Acquisition](02-data-ingestion-and-acquisition/) | 7% |
| 03 | [Data Transformation, Cleansing, and Quality](03-data-transformation-cleansing-and-quality/) | 10% |
| 04 | [Data Sharing and Federation](04-data-sharing-and-federation/) | 5% |
| 05 | [Monitoring and Alerting](05-monitoring-and-alerting/) | 10% |
| 06 | [Cost & Performance Optimisation](06-cost-and-performance-optimisation/) | 13% |
| 07 | [Ensuring Data Security and Compliance](07-data-security-and-compliance/) | 10% |
| 08 | [Data Governance](08-data-governance/) | 7% |
| 09 | [Debugging and Deploying](09-debugging-and-deploying/) | 10% |
| 10 | [Data Modelling](10-data-modelling/) | 6% |

Nearly half the exam (45%) is sections 01, 06, and 03 — writing correct
PySpark/SQL processing code, making it cheap and fast, and keeping the data
clean. Master those before polishing the 5–7% sections.
