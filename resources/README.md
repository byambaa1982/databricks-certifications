## Suggested study order across certifications

The tracks compound — later ones assume earlier ones:

```
Data Engineer Associate  ->  Data Engineer Professional
        |                            |
Data Analyst Associate       Spark Developer Associate
        |
ML Associate  ->  ML Professional  ->  GenAI Engineer Associate
```

The single highest-leverage habit, in every track: **predict the cell's
output before running it.** Every exam shows code and asks what happens —
the notebooks are built so that habit is the workflow.
